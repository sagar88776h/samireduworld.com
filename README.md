# Samir Edu World

Portfolio website for Samir Debnath, History and English teacher — https://samireduworld.com

A single static page (`index.html`) with no build step. Animations use GSAP, ScrollTrigger and Lenis from public CDNs.

## Edit
- WhatsApp number: `WHATSAPP_NUMBER` near the bottom of `index.html` (country code + number, no `+`)
- Photos: `images/samir-river.webp` (hero) and `images/samir-tree.webp` (about)
- Link preview image: `og-image.jpg` (1200 × 630)

## Deploy
Import this repo on Vercel, keep the framework preset as **Other**, and deploy. Every push to `main` redeploys automatically.
